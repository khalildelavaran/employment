# سامانه جامع جذب و استخدام شرکت دستوا (Dasteva Recruitment System)

سامانه تمام‌فارسی (RTL) مدیریت فرآیند جذب، ارزیابی، مصاحبه و استخدام متقاضیان شرکت دستوا، مجهز به پرتال عمومی کارجویان، پنل مدیریت پیشرفته، داشبورد تحلیلی (Analytics)، گالری ۱۰ پوسته اختصاصی و اتصال کامل به سامانه پیامکی **فراز اس‌ام‌اس (IranPayamak)**.

---

## امکانات کلیدی سامانه

1. **پرتال عمومی متقاضیان (`/`)**:
   - مشاهده موقعیت‌های شغلی فعال همراه با شرایط احراز و مزایا
   - احراز هویت دومرحله‌ای (2FA / OTP) از طریق پیامک فراز اس‌ام‌اس پیش از شروع ثبت‌نام یا پیگیری پرونده
   - فرم ثبت‌نام چندمرحله‌ای متقاضیان (مشخصات فردی، سوابق تحصیلی و شغلی، مهارت‌ها و متن کامل رزومه بدون نیاز به آپلود فایل)
   - ارسال خودکار پیامک تایید ثبت‌نام موفق به متقاضی و پیامک اطلاع‌رسانی به مدیر سامانه
   - پیگیری وضعیت پرونده استخدامی صرفاً با **کد ملی** و **شماره موبایل**

2. **پنل مدیریت اختصاصی (`/admin`)**:
   - ورود امن با پشتیبانی از احراز هویت دومرحله‌ای پیامکی مدیر (`admin_2fa_enabled`)
   - **میز کار و لیست متقاضیان**: فیلتر پیشرفته، عملیات گروهی تغییر وضعیت (Bulk Status Update)، و خروجی اکسل (`Export to Excel - .xlsx`)
   - **داشبورد تحلیلی (`Analytics Dashboard`)**: نمودارهای قیف تبدیل متقاضیان، اثربخشی کانال‌های جذب، شاخص زمان استخدام (`Time-to-Hire`) و تحلیل گلوگاه‌های فرآیند جذب با `Recharts`
   - **کانبان ۱۲ مرحله‌ای جذب، تقویم مصاحبه‌ها، بانک سوالات ارزیابی، امتیازدهی و گزارش‌های مدیریتی**
   - **مدیریت سامانه پیامکی فراز اس‌ام‌اس (۳ تب تخصصی)**:
     - **اتصال و 2FA**: استعلام زنده موجودی، خطوط فعال و پترن‌ها، تنظیم خط فرستنده، روش ارسال (پترن سریع / متن دلخواه) و ارسال پیامک آزمایشی
     - **ویرایشگر تعاملی قالب‌ها و پترن‌ها (CRUD)**: ویرایش ۴ قالب خودکار سیستمی + ایجاد، ویرایش، حذف، فعال‌سازی و تست ارسال قالب‌های سفارشی (پترن و متن دلخواه) با پیش‌نمایش زنده و درج یک‌کلیکی متغیرها
     - **گزارش تحویل پیامک‌ها (Delivery Logs)**: نوار شاخص‌های تحویل (کل، موفق، ناموفق، نرخ موفقیت)، جستجو و فیلتر وضعیت/رویداد، نمایش جزئیات کامل پاسخ وب‌سرویس و دکمه **ارسال مجدد (Retry)** برای پیامک‌های ناموفق
   - **گالری ۱۰ پوسته آماده (`Theme Presets Gallery`)** با قابلیت پیش‌نمایش زنده و ذخیره در پایگاه داده

## تنظیم متغیرهای محیطی (`.env`)

کلیدهای محرمانه هرگز در مخزن گیت ذخیره نمی‌شوند. برای اجرای محلی یا استقرار روی سرور، فایل `.env.example` را به `.env` کپی کرده و مقادیر خود را وارد کنید:

```bash
cp .env.example .env
```

متغیرهای کلیدی فراز اس‌ام‌اس:
- `FARAZSMS_BASE_URL=https://api.iranpayamak.com`
- `FARAZSMS_API_KEY=<کلید وب‌سرویس پنل فراز اس‌ام‌اس>`
- `FARAZSMS_KEY_TITLE=emloyment`
- `FARAZSMS_LINE_NUMBER=` *(اختیاری؛ در صورت خالی بودن اولین خط فعال انتخاب می‌شود)*

## راه‌اندازی در محیط توسعه (Local Development)

```bash
# ۱. نصب وابستگی‌ها
npm install

# ۲. اجرای سرور توسعه (پورت 3000)
npm run dev

# ۳. بیلد نسخه نهایی
npm run build
```

## راه‌اندازی دیتابیس Cloudflare D1

فایل اسکیمای دیتابیس در مسیر `migrations/0001_initial_schema.sql` و تنظیمات آن در `wrangler.toml` قرار دارد:

```bash
# ۱. ساخت دیتابیس در Cloudflare D1
npx wrangler d1 create dasteva-recruitment-db

# ۲. قرار دادن database_id دریافتی در فایل wrangler.toml

# ۳. اعمال جداول و داده‌های اولیه روی دیتابیس محلی یا کلودفلر
npx wrangler d1 migrations apply dasteva-recruitment-db --local
npx wrangler d1 migrations apply dasteva-recruitment-db --remote
```
